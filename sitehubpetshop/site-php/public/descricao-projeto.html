Sobre o Projeto

O que é o HubPet?

O HubPet é um projeto acadêmico que conecta donos de pets a petshops e veterinários em um único lugar: catálogo de produtos, agendamento de serviços (banho, tosa, consultas e vacinas) e histórico de pedidos, tudo em uma experiência simples e sem burocracia.

Por que HTML/CSS/JS puro e PHP puro?

Este site é a versão web do app HubPet (feito em Flutter) e segue o mesmo espírito do app original: nada de frameworks pesados dos dois lados. O front-end usa apenas HTML, CSS e JavaScript "vanilla" (sem React/Vue), e o back-end usa PHP puro com PDO (sem Laravel/Symfony) — assim qualquer integrante do grupo consegue ler o código sem precisar aprender uma ferramenta nova.

Tecnologias

  • Front-end: HTML5, CSS3, JavaScript (ES Modules)
  • Back-end: PHP com PDO
  • Banco de dados: MySQL / MariaDB
