# HubPetShop 🐾

 UMA PLATAFORMA DIGITAL QUE REÚNE SERVIÇOS, PRODUTOS E PROFISSIONAIS DO SEGMENTO PET, desenvolvido como projeto da disciplina Projeto Integrador.

## Partes do projeto

- `API/` → API em PHP com banco de dados MySQL
- `DeskHubpetshopAtualizado/` → Versão desktop, feita com Electron (JavaScript)
- `sitehubpetshop/` → Versão web, feita com PHP, HTML e CSS
- `HubPet_completo/` → Versão mobile, feita com Flutter
